# 🚗 AutoMiashs – Outil de gestion de stock automobile

## 📌 Présentation

AutoMiashs est un projet universitaire réalisé dans le cadre d'un projet de gestion.

L'objectif était de développer un outil Excel permettant à un concessionnaire automobile spécialisé dans la vente de véhicules d'occasion de centraliser et de faciliter la gestion de son stock.

L'entreprise utilisait auparavant plusieurs fichiers Excel et des fiches papier, ce qui rendait la saisie, la recherche et le suivi des informations difficiles à long terme.

## 🎯 Problématique

Comment concevoir un outil permettant de :

* simplifier la saisie des données ;
* centraliser les informations liées aux véhicules, clients et transactions ;
* sécuriser la saisie des données ;
* automatiser certaines tâches ;
* faciliter la gestion du stock ;
* produire des synthèses utiles à l'entreprise ;
* aider à optimiser les achats de véhicules.

## 🛠️ Technologies utilisées

* Microsoft Excel
* VBA
* Formulaires et macros Excel
* Fonctions Excel
* Tableaux et bases de données Excel

## ⚙️ Fonctionnalités développées

L'application permet notamment de gérer les données liées :

* aux véhicules ;
* aux clients ;
* aux transactions ;
* au stock.

Elle permet également d'effectuer différentes opérations de gestion et d'automatiser certaines tâches grâce à VBA.

La saisie des données est réalisée à travers l'interface de l'application afin de limiter les modifications directes dans les feuilles Excel.

## 🚗 Gestion du stock

Le projet prend en compte les contraintes liées au parking du concessionnaire :

* nombre limité de places ;
* dimensions des véhicules ;
* occupation de plusieurs places selon la taille du véhicule ;
* places couvertes avec une contrainte de hauteur ;
* places situées au-dessus d'une cuve avec une contrainte de poids.

Ces contraintes permettent de prendre en compte l'occupation réelle du parking lors de la gestion du stock.

## 📊 Analyse des achats

L'outil a également pour objectif d'aider l'entreprise à analyser ses achats de véhicules selon différents critères, notamment :

* durée de présence en stock ;
* prix ;
* occupation du stock ;
* redondance des véhicules.

L'objectif est d'utiliser les données disponibles pour aider à améliorer la gestion des achats et du stock.

## 🔐 Sécurisation

Une attention particulière a été portée à la cohérence des données saisies.

Le gestionnaire de stock n'a pas vocation à modifier directement les feuilles Excel. Les opérations sont réalisées à travers l'interface et les fonctionnalités VBA prévues dans l'application.

## 📁 Fichier

Le fichier principal du projet est :

`AutoMiashs.xlsm`

Les macros doivent être activées dans Excel pour utiliser les fonctionnalités de l'application.
